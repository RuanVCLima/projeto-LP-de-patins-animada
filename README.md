## 📖 Sobre o projeto

Este projeto consiste em uma Landing Page moderna para promover patins, desenvolvida com foco em animações utilizando apenas **HTML** e **CSS**.

Durante o desenvolvimento foram aplicados conceitos como:

- Animações com `@keyframes`
- Transições suaves
- Hover Effects
- Layout Responsivo
- Organização de arquivos CSS
- Posicionamento de elementos
- Flexbox
- Grid Layout

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/RuanVCLima/projeto-LP-de-patins-animada.git
```

Entre na pasta:

```bash
cd projeto-LP-de-patins-animada
```

Abra o arquivo:

```text
index.html
```

Ou utilize a extensão **Live Server** no VS Code.
